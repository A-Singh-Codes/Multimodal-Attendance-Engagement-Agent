# ClassPulse AI — Multimodal Attendance & Session Activity

A local-first Python/Streamlit prototype for classroom session review. It detects visible faces in sampled video frames, associates detections into approximate anonymous tracks, estimates sustained-presence signals and face-centre movement, measures audio energy/quiet intervals, generates transparent teaching prompts, and stores reports locally in SQLite.

## Run on macOS

Python 3.11 or 3.12 is recommended.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
streamlit run app.py
```

Open `http://localhost:8501`.

## Features

- Premium dark-blue dashboard with sidebar navigation.
- Video upload preserved while navigating pages in the same running app session.
- OpenCV Haar face detection and approximate nearest-centre anonymous track association.
- Adjustable sampling interval, max sample count, minimum detections, minimum track duration, and detection coverage within each track’s own observed span (rather than incorrectly dividing by the entire video duration).
- Attendance evidence table with teacher review and optional manual mapping from anonymous track to a roster entry.
- Audio RMS energy and quiet/activity interval segmentation.
- Face-centre movement estimates, timelines, normalized visual/audio comparison, and transparent rule-based teaching suggestions.
- Local SQLite session history and JSON/CSV exports. Uploaded media itself is not stored in the database.
- Runs without cloud APIs or an internet connection after Python packages are installed.

## What this prototype does NOT claim

- It does not identify students from their faces.
- Anonymous tracks may split, merge, or swap IDs due to occlusion, camera movement, lighting, or detection errors.
- Movement estimates are not head-pose estimation. Reliable head pose needs a landmark model and validation, which is not included.
- Audio RMS is sound energy, not speech transcription, speaker identification, or proof of participation.
- The combined chart is a normalized side-by-side activity timeline, not a validated engagement score.
- Recommendations are generated by an explainable offline rules engine, not a trained generative AI model.
- Attendance signals require teacher verification. Do not use them for grading, discipline, or high-stakes decisions.

## Privacy

Use consented sample footage and avoid uploading sensitive classroom recordings to public hosting. The local SQLite database stores analysis reports and teacher review records, but not media files. Delete `classpulse.db` to clear local saved history.
